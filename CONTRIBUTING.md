# Contributing

For development environment setup and local tooling, see the [README](README.md).

Contributors and maintainers working on the simulation repositories should follow
the shared [issue and pull request management guide](docs/issue-and-pr-management.md).
It covers `nomad-simulations`, `simulation-parsers`, `nomad-results-normalizer`,
and `nomad-simulation-apps`. Other projects in this development distribution may
have their own management conventions.

Keep repository-specific setup, test commands, coding conventions, and scientific
validation instructions in the relevant repository's contribution documentation.
The shared guide complements those instructions.
